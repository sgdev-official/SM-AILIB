Save information to persistent memory.

GET STARTED

Install SM-AILIB.

About five minutes. You need Node.js 18+ and Git.

  1. 1

    Check the requirements

    Both commands should print a version.

    node -v
    git --version
  2. 2

    Clone and install

    Run these in a terminal, one after another.

    git clone https://github.com/sgdev-official/SM-AILIB.git
    cd SM-AILIB
    npm install
  3. 3

    Connect your AI client

    Stay inside the SM-AILIB folder so the commands find server.js.

    macOS / Linux

    claude mcp add sm-ailib --env SM_AILIB_HOME="$HOME/.sm-ailib" -- node "$PWD/server.js"

    Windows PowerShell

    claude mcp add sm-ailib --env SM_AILIB_HOME="$HOME\.sm-ailib" -- node "$PWD\server.js"

    Memory and images are stored in the folder set by SM_AILIB_HOME. Change it if you want them somewhere else.

    Add this to your opencode.json, replacing the path with the full path to server.js.

    {
  "mcp": {
    "sm-ailib": {
      "type": "local",
      "command": ["node", "/full/path/to/SM-AILIB/server.js"],
      "environment": { "SM_AILIB_HOME": "~/.sm-ailib" },
      "enabled": true
    }
  }
}
  4. 4

    Check that it works

    Restart your client, then ask it to save a note and read it back.

    sm_ailib_save test-it-works
    sm_ailib_recall test

    If the note comes back, you are done. To update later, run git pull and npm install again.

QUESTIONS?

Frequently asked questions.

What is SM-AILIB?

SM-AILIB is an MCP server and local skill bundle that adds persistent memory, image generation and token modes to supported AI clients.

Which AI clients does it support?

Claude Code and OpenCode today. Any client that can run a local MCP server should work with the same node server.js command.

Where is my memory stored?

On your machine, in the folder set by SM_AILIB_HOME (default ~/.sm-ailib). Nothing is sent anywhere.

Is SM-AILIB free and open source?

Yes. The source is on GitHub under the Apache-2.0 licence.

Does image generation require an internet connection?

Yes. Image generation uses Pollinations AI, so it depends on network availability and that service.
