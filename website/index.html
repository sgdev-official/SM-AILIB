QUICK REFERENCE

Simple commands.

Use these commands to access SM-AILIB capabilities.

@sm-ailib_save <content>

Save information to persistent memory.

@sm-ailib_recall <query>

Search and recall saved information.

@sm_ailib_img <prompt>

Generate an image from a text prompt.

@sm_ailib_0 ... @sm_ailib_5

Switch between the six token modes.

These are skill command formats. The MCP server exposes the corresponding tools to supported AI clients.

QUESTIONS?

Frequently asked questions.

What is SM-AILIB?

SM-AILIB is an MCP server and local skill bundle that adds persistent memory, image generation and token modes to supported AI clients.

Which AI clients does it support?

It provides integration for OpenCode and Claude-compatible environments. Check the repository for the latest setup details.

Where is my memory stored?

Memory is stored locally by the SM-AILIB server. Check the project documentation for its storage location.

Is SM-AILIB free and open source?

Yes. You can explore the source code and project updates on the public GitHub repository.

Does image generation require an internet connection?

Yes. The image generation feature uses Pollinations AI, so it depends on network availability and that service.
