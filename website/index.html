Give text-only AI a memory, a camera and a budget.

sm-ailib adds persistent memory, free image generation and token-budget modes to any text-only model that can call tools. Install it once and it works in Claude Code and OpenCode.

Install sm-ailib

About five minutes. You need Node.js and Git, plus Claude Code or OpenCode.

  1. 1

    Check the requirements

    Node.js 18 or newer and Git must be installed. Run both commands â€“ each should print a version.

    Terminal
    node -v
git --version

    Missing one? Get Node.js from nodejs.org and Git from git-scm.com.

  2. 2

    Clone the repository

    Download the bundle and move into the new folder.

    Terminal
    git clone https://github.com/sgdev-official/SM-AILIB.git
cd SM-AILIB
  3. 3

    Install dependencies

    Run this inside the SM-AILIB folder.

    Terminal
    npm install
  4. 4

    Connect it to your AI client

    Pick your client and your system. Stay inside the SM-AILIB folder so the commands find server.js.

    Terminal
    claude mcp add sm-ailib --env SM_AILIB_HOME="$HOME/.sm-ailib" -- node "$PWD/server.js"
    PowerShell
    claude mcp add sm-ailib --env SM_AILIB_HOME="$HOME\.sm-ailib" -- node "$PWD\server.js"

    Memory and images are stored in the folder set by SM_AILIB_HOME. Change it if you want them somewhere else.

    Add this to your opencode.json, replacing the path with the full path to server.js inside your cloned folder.

    opencode.json
    {
  "mcp": {
    "sm-ailib": {
      "type": "local",
      "command": ["node", "/full/path/to/SM-AILIB/server.js"],
      "environment": { "SM_AILIB_HOME": "~/.sm-ailib" },
      "enabled": true
    }
  }
}
  5. 5

    Check that it works

    Restart your client, then ask it to save something and recall it.

    In your AI chat
    sm_ailib_save test-it-works
sm_ailib_recall test

    If the saved note comes back, youâ€™re done. To update later, run git pull and npm install in the folder.

If something goes wrong

  • Tools donâ€™t appear: restart the client and confirm the server path points to server.js in the cloned folder.
  • claude not found: install Claude Code first, then run the connect command again.
  • Install errors: check node -v is 18 or higher, then run npm install again.

Questions

Which AI clients does it support?

Claude Code and OpenCode today. Any client that can run a local tool server should be able to use it with the same node server.js command.

Does image generation cost anything?

No. Images come from Pollinations AI, which is free, and are saved into your images folder.

Where is my memory stored?

On your own machine, in the folder set by SM_AILIB_HOME. Nothing is added to your prompt until the AI recalls it.

How do I update or remove it?

To update, run git pull and npm install in the folder. To remove it, delete the folder and the sm-ailib entry from your clientâ€™s settings.
